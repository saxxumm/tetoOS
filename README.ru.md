## Что внутри

- **Цвета с обоев.** `scripts/palette.py` находит главные оттенки картинки и пишет светлую и
  тёмную схемы в OKLCH. Сменили обои — весь стол плавно перекрашивается, а новая картинка
  раскрывается кругом из центра. Можно закрепить пресет: Тето, Мику, Рин, Лука, KAITO, GUMI, Неру.
- **Светлая, тёмная, авто.** Авто темнеет ночью (20:00–07:00) или на тёмных обоях.
- **Бар** из пилюль: рабочие столы, плеер, трей, Wi‑Fi/Bluetooth/громкость, погода, часы, дата,
  скриншот / пипетка / запись экрана / ночной свет / тёмная тема / кофеин, батарея, микрофон,
  активное окно. Парящий, сплошной или прозрачный; сверху или снизу.
- **Док** с закреплёнными приложениями, открытыми окнами и плеером.
- **Телефон.** Стоя — лаунчер (приложения, действия, `clip` — буфер обмена, `=2+2` —
  калькулятор) и центр управления (переключатели, ползунки, уведомления, кнопки питания на
  боковой кнопке). На боку — настройки, выбор обоев и страница звука.
- **Звук:** эквалайзер на 10 полос с пресетами (FLAT, BASS, VOCAL, AIR, LOUD, TETO), выбор
  выхода, громкость приложений. Списки Wi‑Fi и Bluetooth.
- **Виджеты:** пузырчатые часы, список дел, карточка пользователя, погода на три дня,
  перекидной календарь, системный монитор, визуализатор музыки (cava). **Режим правки**
  уменьшает стол в рамку: виджеты таскаются мышкой, там же стиль бара и темы.
- **Экран блокировки** (ext-session-lock + PAM), уведомления, OSD, всплывающие карточки
  батареи, погоды, календаря и плеера.
- **Текст песни** (lrclib.net) на баре и караоке в пузыре Тето.

### Мини-Тето

<img src="docs/screens/09-teto-thrown.gif" width="720" alt="бросок Тето">

Живёт в правом нижнем углу.

- **Клик** — отвечает. Пять кликов подряд — обижается.
- **ПКМ** — её меню: поболтать, спеть, потанцевать, батон дня, подсказка, караоке, голос,
  спрятаться.
- **Колёсико** над ней — погладить.
- **Схватить и бросить** — летит, отскакивает от краёв, после сильного броска кружится голова,
  потом сама идёт обратно в угол.
- Печатает реплики по букве с голосом, здоровается по времени суток, танцует под музыку (свои
  песни узнаёт), радуется новым обоям, пугается севшей батареи и горячего процессора, ест
  багет, засыпает, когда ничего не происходит.
- **Батон дня:** раз в день карточка ★1–★5 с предсказанием. Соберите все десять.

Знает только то, что и так знает шелл: время, музыку, батарею, обои. В окна не заглядывает.

Пиксельную Тето нарисовал [saxxumm](https://github.com/saxxumm). Свои кадры (`idle.png`,
`blink.png`, `talk.png`, `happy.png`, `sleep.png`, `shock.png`, `dizzy.png`, `cheer.png`,
`wink.png`, `eat.png`, `chew.png`, любого размера) кладите в `~/.local/share/tetoos/teto/` —
она наденет их вместо встроенных.

## Установка

```bash
git clone https://github.com/saxxumm/tetoOS ~/.config/quickshell/tetoos
~/.config/quickshell/tetoos/install.sh
```

Установщик спрашивает перед каждым шагом: пакеты (pacman, для AUR — paru/yay), шрифты
(Fredoka, Material Symbols), четыре обоев с Тето с wallhaven.cc, эквалайзер PipeWire и
подключение к композитору. `./install.sh --help` — все ключи, `--yes` — всё по умолчанию.

Потом остановите другой шелл (waybar, другой конфиг Quickshell, демон уведомлений) и:

```bash
tetoos start
```

### Hyprland

- **0.55+ (`hyprland.lua`)**: пишется `~/.config/hypr/tetoos.lua`, в `hyprland.lua` добавляется
  `pcall(require, "tetoos")`.
- **Старше (`hyprland.conf`)**: пишется `~/.config/hypr/tetoos.conf` и строка `source =`.

Привязываются только клавиши шелла, ваши клавиши окон и столов не трогаются.
`tetoos revert hyprland` убирает всё обратно. Обзора холста в Hyprland нет, поэтому пилюля
стола на баре и кнопка-сетка в доке открывают лаунчер, а ПКМ по пустому столу — меню стола.

### sxmwm

`tetoos use sxmwm` добавляет автозапуск, свободные клавиши шелла и ПКМ по холсту в
`~/.config/sxmwm/config.toml` (сначала делает копию). Конфиг под angelOS переводится
привязка за привязкой.

## Клавиши

| Клавиша | |
|---|---|
| `Super+D` | лаунчер |
| `Super+N` | центр управления |
| `Super+/` | настройки |
| `Super+Shift+B` | обои |
| `Super+Shift+V` | буфер обмена |
| `Super+Shift+D` | правка стола |
| `Super+Shift+.` | светлая / тёмная |
| `Super+Shift+E` | меню питания |
| `Super+Alt+Y` | караоке Тето |
| `Super+L` | блокировка |
| громкость / яркость / медиа | с экранной подсказкой |

## Командная строка

```
tetoos start | stop | restart | status
tetoos ipc <функция> [аргументы]  # launcher, control, settings, wallpapers, sound, wifi,
                                  # bluetooth, clipboard, power, edit, lock, record,
                                  # setWallpaper <путь>, preset <имя>, mode <light|dark|auto>,
                                  # tetoSay <текст>, tetoSing, tetoDance, tetoEat, bread, …
tetoos palette <картинка>         # перекрасить по картинке
tetoos use | revert [hyprland|sxmwm]
```

Настройки — в `~/.local/state/tetoos/config.json` (или `$TETOOS_STATE`).

## Проверка без выхода из сессии

Во вложенном композиторе:

```bash
TETOOS_DEMO=1 TETOOS_NESTED=1 TETOOS_STATE=/tmp/tetoos-demo qs -p ~/.config/quickshell/tetoos
```

`TETOOS_DEMO=1` подменяет всё личное (имя, сети, устройства, музыку, город) — так сняты
скриншоты. `TETOOS_NESTED=1` не пускает тестовый экземпляр к шине уведомлений, динамикам и
настоящему эквалайзеру.
